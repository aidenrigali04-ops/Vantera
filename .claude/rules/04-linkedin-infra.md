# LinkedIn outreach infrastructure

**Unipile API** behind a Vantera-owned `linkedin-infra` interface (connect / invite / message / replies) — same swappable pattern as `email-infra`. Users connect their own LinkedIn account through Unipile's white-labeled hosted auth (login, 2FA, checkpoints) inside Vantera onboarding; the Trigger.dev scheduler then sends connection requests, messages, and InMail server-side, with reply webhooks feeding the shared reply-classification handler. The previous Chrome-extension approach is retired: it required the user's browser to be open (breaks autonomous agents) and added install friction. Safety limits live in Vantera's scheduler, not the provider — ramp new accounts, ~100 invites/week ceiling, randomized human-like pacing, non-configurable below safety thresholds. Per-account pricing maps onto Stripe plans.
